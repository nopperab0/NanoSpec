# A100 measurement bundle

[English report](RESULTS.md) · [中文报告](RESULTS.zh-CN.md) · [Tables](TABLES.md)

The published tables cover 18 performance cells and eight diagnostic profiles.

`metrics.csv` and `profiling.csv` are generated by `tools/build_reports.py`.
`data/jetspec.json` contains the six JetSpec cells and four profiling summaries from job 24896042.
`data/cells`, `data/events`, `profiling` and `environment` contain the archived comparison data from job 24846937.

Paths and device identifiers are redacted; numeric timing measurements are preserved. Output token IDs are omitted.
The original frozen input panel was not included in the downloaded source archive; its hash remains in `data/run.json`.
See the reports for limitations and instructions before interpreting or replaying these results.
